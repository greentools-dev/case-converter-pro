Variable Naming Guide & Frequently Asked Questions

When should I use camelCase vs snake_case?

In JavaScript, TypeScript, and Java, variables and function names follow camelCase. In Python, Ruby, and SQL relational databases, identifiers, column names, and methods conventionally use snake_case.

How does the slugifier handle diacritics and accents?

Foreign language characters with accents (like é, ö, à, ñ) are decomposed and normalized into standard ASCII equivalents (e, o, a, n) before non-alphanumeric symbols are stripped for clean URL permalinks.

What does CONSTANT_CASE signify?

Also known as SCREAMING_SNAKE_CASE or MACRO_CASE, this convention is used across C++, Python, Node.js, and Java for immutable environment variables, constants, and global config flags.

Yes. All string operations and regex tokenizations run 100% locally in your browser session. Your proprietary code names and text strings never leave your device.
